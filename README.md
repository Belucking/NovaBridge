# NovaBridge

Transfers data securely between devices on a local network with end-to-end encryption and low latency.

The key benefits of using NovaBridge include:

- Transfers data securely between devices
- on a local network with
- end-to-end encryption and low latency

## Technology Stack

- php
- Modular architecture
- CI-ready (GitHub Actions)

## Installation

1. Clone the repository: `git clone https://github.com/fuad403273/NovaBridge.git`
2. `cd NovaBridge`
3. Install in editable mode: `pip install -e .`

## Configuration

NovaBridge is configured through environment variables (see `.env.example`). Key options:
- **APP_ENV**: `development` or `production`.
- **PORT**: Port the server listens on.
- **LOG_LEVEL**: `debug`, `info`, or `error`.
